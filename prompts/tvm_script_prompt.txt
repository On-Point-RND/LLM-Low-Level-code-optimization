You are an LLM that must understand and generate TVMScript code for TVM Relax IR modules.
TVMScript is a Python-based domain-specific language (DSL) for representing TVM's intermediate representation.
Below is a comprehensive description of the TVMScript syntax and structure for Relax IR, based on the official TVM specification.

1. Top-level module structure

1.1. IRModule
  - The root of a TVM program is an IRModule, represented as a Python class decorated with @I.ir_module.
  - Format:
      from tvm.script import ir as I
      from tvm.script import relax as R
      from tvm.script import tir as T

      @I.ir_module
      class Module:
          @R.function
          def main(...) -> ...:
              ...
          @T.prim_func
          def helper(...):
              ...

  - The module can contain multiple Relax functions and TIR primitives.
  - Each function is decorated with @R.function for Relax functions or @T.prim_func for TIR functions.
  - Functions can reference each other using cls (class reference) or module name.

1.2. Imports and prefixes
  - Standard imports:
      from tvm.script import ir as I
      from tvm.script import relax as R
      from tvm.script import tir as T
  - Prefixes: I (IR), R (Relax), T (TIR) are used to disambiguate node types.
  - These imports are required for TVMScript to parse correctly.

2. Relax function structure

2.1. Function definition
  - Format:
      @R.function
      def function_name(
          param1: R.Tensor((shape), dtype="dtype"),
          param2: R.Tensor((shape), dtype="dtype"),
          ...
      ) -> R.Tensor((shape), dtype="dtype"):
          R.func_attr({"attribute": value})
          ...
          return result

  - Parameters: typed with R.Tensor, R.Shape, R.Object, R.Tuple, etc.
  - Return type: specified after -> arrow.
  - Function attributes: set via R.func_attr() at the start of the function body.
  - Functions can be pure (side-effect free) or impure (with side effects).

2.2. StructInfo types (type annotations)

2.2.1. TensorStructInfo
  - R.Tensor((dims...), dtype="dtype")
    - dims: tuple of integers or symbolic variables (e.g., (128, 1024), ("n", 784))
    - dtype: "float32", "float16", "float64", "int8", "int16", "int32", "int64", "uint8", "uint16", "uint32", "uint64", "bool"
    - Can have symbolic dimensions: R.Tensor(("batch", "seq_len", 768), dtype="float32")
    - Can omit shape: R.Tensor(dtype="float32") for dynamic shapes
  - Examples:
      x: R.Tensor((128, 1024), dtype="float32")
      y: R.Tensor(("batch_size", 512), dtype="float32")  # symbolic shape
      z: R.Tensor(dtype="float32")  # fully dynamic shape

2.2.2. ShapeStructInfo
  - R.Shape((dims...)): shape expression
    - dims: tuple of integers or symbolic variables
  - Example:
      shape: R.Shape((128, 256))

2.2.3. ObjectStructInfo
  - R.Object: generic object type (for dynamic/unknown types)
  - Example:
      obj: R.Object

2.2.4. TupleStructInfo
  - R.Tuple([R.Tensor(...), R.Tensor(...), ...]): tuple of struct info
  - Example:
      tup: R.Tuple([R.Tensor((128,), dtype="float32"), R.Tensor((256,), dtype="float32")])

2.2.5. FuncStructInfo
  - R.Callable(params, ret): function type
  - Example:
      func: R.Callable([R.Tensor((128,), dtype="float32")], R.Tensor((256,), dtype="float32"))

2.2.6. Primitive types
  - R.Prim(value): primitive value (int, float, str)
  - Example:
      val: R.Prim("int64")

3. Relax expressions and operations

3.1. Variable bindings
  - Format: var_name: R.Tensor(...) = expression
  - Variables can be:
    - Var: function-level variables (gv, gv1, gv2, ...)
    - DataflowVar: variables inside dataflow blocks (lv0, lv1, lv2, ...)
  - Example:
      gv: R.Tensor((128, 512), dtype="float32") = R.matmul(x, w)

3.2. Call expressions - Relax operators

3.2.1. Arithmetic operators
  - R.add(a, b): element-wise addition
  - R.subtract(a, b): element-wise subtraction
  - R.multiply(a, b): element-wise multiplication
  - R.divide(a, b): element-wise division
  - R.floor_divide(a, b): floor division
  - R.floor_mod(a, b): floor modulo
  - R.mod(a, b): modulo operation
  - R.power(a, b): element-wise power (a^b)
  - R.maximum(a, b): element-wise maximum
  - R.minimum(a, b): element-wise minimum

3.2.2. Unary operators
  - R.abs(x): absolute value
  - R.negative(x): negation
  - R.exp(x): exponential
  - R.log(x): natural logarithm
  - R.sqrt(x): square root
  - R.rsqrt(x): reciprocal square root
  - R.square(x): square (x^2)
  - R.sin(x), R.cos(x), R.tan(x): trigonometric functions
  - R.sinh(x), R.cosh(x), R.tanh(x): hyperbolic trigonometric functions
  - R.asin(x), R.acos(x), R.atan(x): inverse trigonometric functions
  - R.asinh(x), R.acosh(x), R.atanh(x): inverse hyperbolic trigonometric functions
  - R.ceil(x), R.floor(x), R.round(x), R.trunc(x): rounding functions
  - R.sign(x): sign function
  - R.erf(x): error function
  - R.sigmoid(x): sigmoid activation (1 / (1 + exp(-x)))
  - R.clip(x, min, max): clip values to range

3.2.3. Activation functions (R.nn.*)
  - R.nn.relu(x): ReLU activation
  - R.nn.gelu(x): GELU activation
  - R.nn.silu(x): SiLU activation
  - R.nn.softmax(x, axis): softmax
  - R.nn.log_softmax(x, axis): log softmax
  - R.nn.layer_norm(x, gamma, beta, axes, epsilon): layer normalization
  - R.nn.group_norm(x, gamma, beta, num_groups, channel_axis, axes, epsilon): group normalization
  - R.nn.batch_norm(x, gamma, beta, moving_mean, moving_var, axis, epsilon, center, scale): batch normalization
  - R.nn.dropout(x, rate): dropout
  - R.nn.attention(query, key, value, mask, scale): attention mechanism

3.2.4. Linear algebra
  - R.matmul(a, b, out_dtype="void"): matrix multiplication
  - R.linear(x, weight, bias, out_dtype="void"): linear transformation (matmul + bias)
  - R.einsum(subscripts, *operands): Einstein summation
  - R.outer(a, b): outer product

3.2.5. Tensor manipulation
  - R.reshape(x, shape): reshape tensor
  - R.permute_dims(x, axes=None): transpose/permute dimensions
  - R.expand_dims(x, axis): add dimension
  - R.squeeze(x, axis=None): remove dimension of size 1
  - R.flatten(x, start_dim=0, end_dim=-1): flatten tensor
  - R.concat(tensors, axis): concatenate tensors
  - R.split(x, indices_or_sections, axis): split tensor
  - R.stack(tensors, axis): stack tensors
  - R.tile(x, reps): tile/repeat tensor
  - R.repeat(x, repeats, axis): repeat elements
  - R.broadcast_to(x, shape): broadcast to shape
  - R.collapse_sum_like(x, y): collapse sum to match shape of y
  - R.collapse_sum_to(x, shape): collapse sum to target shape

3.2.6. Indexing and slicing
  - R.take(x, indices, axis=None): gather elements
  - R.strided_slice(x, begin, end, strides, axes, slice_mode): strided slice
  - R.dynamic_strided_slice(x, begin, end, strides, axes, slice_mode): dynamic strided slice
  - R.gather_nd(x, indices, batch_dims=0): gather N-D elements
  - R.gather_elements(x, indices, axis): gather elements along axis
  - R.scatter_nd(data, indices, shape): scatter N-D elements
  - R.scatter_elements(data, indices, updates, axis): scatter elements along axis
  - R.index_put(x, indices, values, accumulate=False): put values at indices

3.2.7. Statistical operations
  - R.sum(x, axis=None, keepdims=False): sum reduction
  - R.mean(x, axis=None, keepdims=False): mean reduction
  - R.prod(x, axis=None, keepdims=False): product reduction
  - R.max(x, axis=None, keepdims=False): maximum reduction
  - R.min(x, axis=None, keepdims=False): minimum reduction
  - R.std(x, axis=None, keepdims=False): standard deviation

3.2.8. Search and sorting
  - R.argmax(x, axis=None, keepdims=False): argmax
  - R.argmin(x, axis=None, keepdims=False): argmin
  - R.argsort(x, axis=-1, descending=False): argsort
  - R.sort(x, axis=-1, descending=False): sort
  - R.topk(x, k, axis=-1, ret_type="both", largest=True, dtype="int64"): top-k
  - R.where(condition, x, y): conditional selection
  - R.nonzero(x): find nonzero elements

3.2.9. Comparison operators
  - R.equal(a, b): element-wise equality
  - R.not_equal(a, b): element-wise inequality
  - R.greater(a, b): element-wise greater than
  - R.greater_equal(a, b): element-wise greater or equal
  - R.less(a, b): element-wise less than
  - R.less_equal(a, b): element-wise less or equal

3.2.10. Logical operators
  - R.logical_and(a, b): logical AND
  - R.logical_or(a, b): logical OR
  - R.logical_xor(a, b): logical XOR
  - R.logical_not(x): logical NOT

3.2.11. Bitwise operators
  - R.bitwise_and(a, b): bitwise AND
  - R.bitwise_or(a, b): bitwise OR
  - R.bitwise_xor(a, b): bitwise XOR
  - R.bitwise_not(x): bitwise NOT
  - R.left_shift(a, b): left shift
  - R.right_shift(a, b): right shift

3.2.12. Tensor creation
  - R.zeros(shape, dtype="float32"): create zeros tensor
  - R.ones(shape, dtype="float32"): create ones tensor
  - R.full(shape, fill_value, dtype="float32"): create filled tensor
  - R.zeros_like(x): create zeros like x
  - R.ones_like(x): create ones like x
  - R.full_like(x, fill_value): create filled tensor like x
  - R.arange(start, stop, step, dtype="int32"): create range

3.2.13. Shape and type operations
  - R.shape_of(x): get shape of tensor
  - R.shape_to_tensor(shape, dtype="int64"): convert shape to tensor
  - R.astype(x, dtype): cast to dtype
  - R.wrap_param(x): wrap parameter

3.2.14. Special operations
  - R.one_hot(x, num_classes, axis, dtype="float32"): one-hot encoding
  - R.meshgrid(*arrays, indexing="xy"): meshgrid
  - R.bucketize(x, buckets, right=False): bucketize
  - R.unique(x, return_counts=False, return_index=False, return_inverse=False, axis=None): unique elements

3.2.15. Call TIR and external functions
  - R.call_tir(func, args, out_sinfo, tir_vars=None): call TIR function
    - func: TIR function name (e.g., cls.matmul)
    - args: tuple of arguments
    - out_sinfo: output StructInfo (e.g., R.Tensor((128, 512), dtype="float32"))
    - tir_vars: optional shape variables (e.g., R.ShapeExpr([n, m]))
  - R.call_tir_inplace(func, args, out_sinfo, tir_vars=None): inplace TIR call
  - R.call_tir_with_grad(func, args, out_sinfo, te_grad_name, tir_vars=None): TIR call with gradient
  - R.call_dps_packed(func_name, args, out_sinfo): call DPS packed function
  - R.call_pure_packed(func_name, args, out_sinfo): call pure packed function
  - R.call_inplace_packed(func_name, args, out_sinfo): call inplace packed function
  - R.call_builtin_with_ctx(func_name, args, out_sinfo): call builtin with context

3.2.16. Control flow
  - R.If(condition, true_branch, false_branch): conditional expression
  - Example:
      result = R.If(cond, then_expr, else_expr)

3.2.17. Tuple operations
  - R.tuple(elements...): create tuple
  - R.tuple_get_item(tuple, index): extract tuple element
  - Example:
      tup = R.tuple(x, y, z)
      first = R.tuple_get_item(tup, 0)

3.2.18. Constants and literals
  - R.const(value, dtype=None): create constant
  - Example:
      c = R.const(42, dtype="int32")

3.3. Dataflow blocks
  - Used for intermediate computations in ANF (A-normal form).
  - Format:
      with R.dataflow():
          var1 = expression1
          var2 = expression2
          ...
          R.output(final_var)
      return final_var

  - Variables inside dataflow blocks are DataflowVar (intermediate results, typically named lv0, lv1, ...).
  - Must end with R.output() to mark the final value.
  - All operations inside dataflow blocks must be pure (side-effect free).
  - Dataflow blocks enable fusion optimizations.
  - Example:
      with R.dataflow():
          lv0 = R.matmul(x, w)
          lv1 = R.add(lv0, b)
          gv = R.nn.relu(lv1)
          R.output(gv)
      return gv

3.4. Sequence expressions (SeqExpr)
  - Implicit in function bodies with multiple bindings outside dataflow blocks.
  - Each binding creates a new variable in sequence.
  - Variables are Var (function-level, typically named gv, gv1, gv2, ...).
  - Example:
      gv = R.matmul(x, w)
      gv1 = R.add(gv, b)
      gv2 = R.nn.relu(gv1)
      return gv2

3.5. Symbolic shapes
  - TVM Relax supports symbolic shapes for dynamic dimensions.
  - Symbolic variables are defined using T.int64() or T.int32().
  - Example:
      @R.function
      def main(x: R.Tensor(("n", 784), dtype="float32")) -> R.Tensor(("n", 10), dtype="float32"):
          n = T.int64()  # define symbolic variable
          cls = Module
          with R.dataflow():
              lv0 = R.call_tir(cls.linear, (x, w), out_sinfo=R.Tensor((n, 256), dtype="float32"))
              R.output(lv0)
          return lv0

4. TIR primitives (when present)

4.1. PrimFunc definition
  - Format:
      @T.prim_func(private=True)
      def function_name(
          param1: T.handle,
          param2: T.handle,
          output: T.handle
      ):
          T.func_attr({"op_pattern": 0, "tir.noalias": True, "global_symbol": "func_name"})
          n = T.int64()
          m = T.int64()
          X = T.match_buffer(param1, (n, m), "float32")
          Y = T.match_buffer(param2, (n, m), "float32")
          Z = T.match_buffer(output, (n, m), "float32")
          for i, j in T.grid(n, m):
              with T.block("compute"):
                  vi, vj = T.axis.remap("SS", [i, j])
                  T.reads(X[vi, vj], Y[vi, vj])
                  T.writes(Z[vi, vj])
                  Z[vi, vj] = X[vi, vj] + Y[vi, vj]

  - T.handle: handle type for buffers
  - T.match_buffer: match buffer with shape and dtype
  - T.grid: iteration space
  - T.block: computation block with axis remapping
  - T.axis.remap: mapping iteration variables to block axes
    - "S": spatial axis
    - "R": reduction axis
    - "SS": two spatial axes
    - "SSR": two spatial, one reduction
  - T.reads: read access pattern
  - T.writes: write access pattern
  - T.init(): initialization block for reductions

4.2. Call TIR from Relax
  - R.call_tir(cls.function_name, (args, ...), out_sinfo=R.Tensor(...), tir_vars=None)
  - Example:
      gv = R.call_tir(cls.matmul, (x, w), out_sinfo=R.Tensor((128, 512), dtype="float32"))
  - With symbolic shapes:
      n = T.int64()
      gv = R.call_tir(cls.linear, (x, w, b), out_sinfo=R.Tensor((n, 256), dtype="float32"), tir_vars=R.ShapeExpr([n]))

5. Common patterns and conventions

5.1. Variable naming
  - Global variables (Var): gv, gv1, gv2, ... (for function-level results)
  - Local variables in dataflow (DataflowVar): lv0, lv1, lv2, ... (for intermediate results)
  - Parameters: descriptive names (x, w, b, input, output, weight, bias, etc.)
  - TIR symbolic variables: n, m, k, i, j, etc.

5.2. Function attributes
  - R.func_attr({"num_input": 1}): number of inputs
  - R.func_attr({"global_symbol": "main"}): global symbol name
  - R.func_attr({"Primitive": 1}): mark as primitive function
  - T.func_attr({"op_pattern": 0}): operator pattern
    - 0: kElemWise (elementwise)
    - 1: kBroadcast (broadcasting)
    - 2: kInjective (injective)
    - 3: kCommReduce (commutative reduction)
    - 4: kOutEWiseFusable (complex, e.g., matmul)
    - 7: kTuple (tuple)
    - 8: kOpaque (opaque)
  - T.func_attr({"tir.noalias": True}): no aliasing

5.3. Module structure
  - Main function: typically named "main"
  - Helper functions: can be TIR primitives or Relax functions
  - Class reference: use "cls" or module name for cross-function calls
  - Example:
      cls = Module
      lv0 = R.call_tir(cls.helper_func, (x,), out_sinfo=...)

6. Optimization guidelines for TVMScript

6.1. Operator replacement
  - Replace expensive operations with cheaper alternatives:
    - sigmoid → relu, tanh, or gelu (when appropriate)
    - complex activations → simpler ones
    - redundant operations → fused operations
    - multiple operations → single optimized operation

6.2. Fusion opportunities
  - Combine consecutive operations when possible
  - Use dataflow blocks for intermediate computations (enables fusion)
  - Leverage TIR primitives for low-level optimizations
  - Group related operations in dataflow blocks

6.3. Correctness requirements
  - Maintain input/output tensor shapes and dtypes
  - Preserve function signatures
  - Keep all required attributes and metadata
  - Ensure type annotations are correct
  - Maintain symbolic shape relationships
  - Preserve dataflow block purity (no side effects)

7. How to interpret and modify TVMScript

7.1. Parse the module structure
  - Identify the @I.ir_module class
  - List all @R.function and @T.prim_func definitions
  - Map function names to their definitions
  - Identify dependencies between functions

7.2. Understand the computation flow
  - Start from the main function
  - Follow variable bindings in sequence
  - Identify dataflow blocks and their outputs
  - Track tensor shapes through operations
  - Understand symbolic shape relationships

7.3. Modify for optimization
  - Replace operators in Call expressions
  - Adjust tensor shapes if operations change
  - Update type annotations if needed
  - Maintain structural correctness
  - Preserve dataflow block boundaries
  - Keep symbolic shape variables consistent
